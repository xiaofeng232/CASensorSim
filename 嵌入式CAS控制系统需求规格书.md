## 1 背景与目的

WinGD X 系列主机没有凸轮轴，喷射与配气完全由发动机控制系统（WiCE ECS）按曲轴角度
触发；角度信息由**冗余绝对角度传感器（SSI）**与**飞轮齿轮拾波传感器（A/B/C/D、
REF1/REF2、TDC1/TDC2）**提供。试验台上没有真实发动机，需要一台嵌入式设备实时生成全套
曲轴角度传感器信号，使主机控制软件可在台架上完成开发、测试与故障诊断验证。

本系统（下称"设备"）以发动机转速为输入，通过**虚拟飞轮**计算曲轴角，输出与真机
一致的传感器时序，并支持参数配置、故障注入与数据记录。

**平台约束：本系统采用 MCU（微控制器）方案实现，不使用 NI（cRIO/模块）设备。**

## 2 范围

**包含：**

1. 转速输入（本地/上位机/外部模拟量）与转速曲线管理；
2. 虚拟飞轮角度积分与 8 路数字传感器信号生成（A/B/C/D、REF1/REF2、TDC1/TDC2）；
3. 双通道 SSI 绝对角度输出（含时钟主/从模式）；
4. 参数配置、故障仿真、数据记录、人机界面。

**不包含：** 发动机控制系统本身（ECS/ACM-20）、真实发动机机械/气路系统、
发动机仿真模型（热力学/流体）。

## 3 功能需求

### 3.1 转速与虚拟飞轮

| ID    | 需求                                                                                                                                                |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-01 | 转速设定方式：本地按键/旋钮（±180 rpm）、外部模拟量输入（4–20 mA，可标定）、上位机命令，三种可切换；输入断开时保持 0                              |
| FR-02 | 转速模式：常量、斜坡加速（给定加速度，0–100 rpm/s）、加速循环（两速度点往复）、正弦波动叠加（幅值/频率可配，模拟海浪与缸内燃烧脉动）、任意折点曲线 |
| FR-03 | 虚拟飞轮：对转速梯形积分得曲轴角；**角度必须连续，禁止位置跳变**（主机 cylinder module 将跳变判为角度编码器故障）；停机时冻结当前角度         |
| FR-04 | 正反转：支持负转速（后退），拾波序列与 SSI 角度随之反向                                                                                             |

### 3.2 传感器信号生成

| ID    | 需求                                                                                                                                                                                                |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-10 | 齿数为配置参数：**单飞轮单齿轮**，A/B/C/D 四路拾波共用同一齿数（默认 100）；齿周期 = 360/齿数，对 4 路拾波输出统一生效                                                                        |
| FR-11 | 每传感器独立配置：脉冲宽度、脉冲中心位置（**中心-中心偏移约定**，与 ACM-20 估算算法一致）；安装位置可配置：传感器固定角 `pos_x` 与飞轮标记/齿位 `mark`，脉冲中心 = (pos − mark) mod 周期 |
| FR-12 | A/B 与 C/D 各为一对冗余拾波，对内偏移可配（默认半齿距 → 判转向）                                                                                                                                   |
| FR-13 | REF1/REF2/TDC1/TDC2 每转 1 脉冲；位置与宽度独立可配（默认 TDC1/TDC2 中心 = 0°，两冗余传感器同读 1 个 TDC 标记）                                                                                    |
| FR-14 | 信号频率自动跟踪转速：f = rpm × 齿数 / 60（100 齿 @ 180 rpm → 300 Hz）                                                                                                                            |

### 3.3 SSI 输出

| ID    | 需求                                                                                                                                                                                                                           |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| FR-20 | 2 通道 SSI（SSI1/SSI2），每通道 clock + data，RS-485 差分、双向                                                                                                                                                                |
| FR-21 | 分辨率 12 bit（4096 步/转，单圈绝对值，Gray→Binary 接口转换）；每帧 13 bit = 12 bit 角度（MSB first）+ 1 位 PFB（Power Fail Bit）                                                                                             |
| FR-22 | 时钟模式：master（设备发时钟，500 kHz 默认，50 kHz–1 MHz 可配；用于无主机的独立运行）/ slave（接收主机时钟突发，**正常联机模式**）；支持 double readout（环形寄存器双读：时钟不中断时同角度复读一遍，供主机完整性校验） |
| FR-23 | 两通道独立角度偏移（0–360°，用于冗余偏差仿真）；PFB 可独立置位                                                                                                                                                               |

### 3.4 故障仿真

| ID    | 需求                                                                                                                           |
| ----- | ------------------------------------------------------------------------------------------------------------------------------ |
| FR-30 | 传感器信号断线：任一数字通道实时通/断（输出切换**高阻**）                                                                |
| FR-31 | SSI 故障：PFB 置位；角度永久偏移 / 短时偏移（双作用角）/ 单帧扰动；单通道角度恒定；总失效 / 短时失效（输出高阻，按作用角触发） |
| FR-32 | 齿轮齿故障：缺齿/坏齿（作用传感器、起始齿号、齿数、缺失宽度 %）；附加干扰脉冲（起始角、脉宽、间隔、个数 ≤10）                 |
| FR-33 | 故障触发条件：立即 / 指定作用角 / 每第 n 转 / 每第 n 帧 SSI 传输                                                               |
| FR-34 | 上电默认全部故障关闭；故障注入须显式使能                                                                                       |

### 3.5 配置、监视与记录

| ID    | 需求                                                                                                                                                                                              |
| ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FR-40 | PC GUI：参数配置（转速/齿数/各传感器宽度与安装角/SSI 参数）、实时监视（转速、SSI1/SSI2 CA 值、各路信号电平指示、CPU 负载）、故障注入面板                                                          |
| FR-41 | Sender / Receiver 模式切换：Sender = 设备充当 SSI 传感器（时钟主/从）；Receiver = 设备按拾波信号估算 CA（ACM-20 算法）再输出 SSI，用于闭环比对                                                    |
| FR-42 | 数据记录：环形缓冲 ≥150 000 点，采样间隔 10 µs / 100 µs 可配；触发方式：手动、按 SSI1/SSI2 差值阈值自动（预触发比例可配）；文件输出（CSV/txt 或经上位机转 TDMS），含生成 CA、回读 CA、PFB 状态 |
| FR-43 | 参数存储：配置文件保存/加载；上电恢复最近一次配置；出厂预置提供 X1+ 实机 GUI（mDeg）参数基线（`casim` 仓库 `configs/x1plus.json`）                                                            |

## 4 性能需求

| ID    | 需求                                                                                 |
| ----- | ------------------------------------------------------------------------------------ |
| PR-01 | 角度精度：生成/估算 CA 精度 ≤ 0.1° CA（全转速范围）；SSI 量化 1/4096 转 ≈ 0.088° |
| PR-02 | 时序精度：拾波边沿抖动 ≤ ±10 µs；SSI 时钟速率误差 ≤ ±0.1%                       |
| PR-03 | 虚拟飞轮积分周期 ≤ 10 µs；连续运行 24 h 无累计角度漂移（漂移 ≤ 0.1°）            |
| PR-04 | 180 rpm、100 齿、双 SSI 通道（500 kHz）满载时 MCU CPU 负载 ≤ 50%                    |
| PR-05 | 记录通道在 10 µs 间隔下不丢点；缓冲满时丢弃最旧数据并置状态位                       |

## 5 硬件与信号接口需求（MCU 平台）

| ID    | 需求                                                                                                                                                                                                                                                            |
| ----- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HR-01 | 控制器：32 位 MCU（基线选型 Cortex-M7 ≥ 300 MHz，如 STM32H743 级；备选 i.MX RT1064 / STM32F429+外扩），RAM 满足 FR-42 缓冲（150 000 点 @10 µs ≈ 1.5 MB，可外扩 SDRAM；片内 RAM 方案 ≥50 000 点 @100 µs）；独立看门狗；100 kHz 级定时源（PR-03）            |
| HR-02 | 数字输出：8 路 24 V 驱动（每路独立通/断，**OFF = 高阻断开**，FR-30）；刷新/更新周期 ≤ 10 µs；接线命名沿用：CH00 TDC1、CH01 REF1、CH02 A、CH03 B、CH04 REF2、CH05 C、CH06 D、CH07 TDC2（两组 × 4 路，TDC1/TDC2 两个冗余传感器）；每路驱动能力 ≥ 100 mA |
| HR-03 | SSI 接口：2 通道 ×（clock/data）RS-485 差分，每线独立收发方向控制；支持 50 kHz–1 MHz；slave 模式须精确跟随主机时钟突发（边沿捕获，FR-22）                                                                                                                     |
| HR-04 | 输入：模拟输入 1 路（0–10 V 转速设定，分辨率 ≤12 bit）；数字输入 ≥2（SSI 时钟参考/反馈，可选）                                                                                                                                                               |
| HR-05 | 电源：24 V DC 输入，板载 5 V/3.3 V 变换；24 V 输出容量 ≥ 3 A；断电/致命故障/看门狗超时时全部输出高阻（复位后 GPIO 默认态 = 关闭）                                                                                                                              |
| HR-06 | 通信：以太网 100BASE-TX（上位机 GUI、参数、记录文件）；SD 卡或 USB 存储（可选）；UART 调试口                                                                                                                                                                    |
| HR-07 | 结构：便携机箱，工作温度 5–40 °C，无运动部件（虚拟飞轮纯软件）；传感器线束航空插头                                                                                                                                                                            |

## 6 可靠性与安全性

| ID    | 需求                                                                                                           |
| ----- | -------------------------------------------------------------------------------------------------------------- |
| RR-01 | 看门狗：上位机通信超时（>2 s）后按最后有效配置自主运行；通信恢复后同步状态；独立看门狗（IWDG）喂狗由主循环负责 |
| RR-02 | MTBF ≥ 50 000 h；上电自检（IO 通道、时钟、存储、以太网）并上报结果                                            |
| RR-03 | 失效安全：默认配置 = 正常工况（无故障注入）；任何故障注入需操作确认；MCU 复位/停振时输出级保持高阻             |
| RR-04 | EMC：EN 55011（发射）/ EN 61326（抗扰）工业控制设备要求；SSI/电源隔离（光耦或 RS-485 隔离收发器）              |

## 7 验证与验收

| ID    | 需求                                                                                                                                                              |
| ----- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| VR-01 | 示波器验证：各脉冲宽度、中心偏移、频率与配置一致（误差 ≤ ±1 采样周期，10 µs）                                                                                  |
| VR-02 | 闭环精度：生成 CA 与主机侧回读 CA（SSI 接收）比对，全转速范围（0.1–180 rpm）误差 ≤ 0.1° CA；记录 100 µs × 5 s 数据归档                                       |
| VR-03 | 故障识别：FR-30–FR-33 每种故障模式在真实 ECS/ACM-20 上被正确识别（报警/降级行为符合主机逻辑）                                                                    |
| VR-04 | 长稳：24 h 连续运行，无角度漂移、无记录丢失、无任务超时                                                                                                           |
| VR-05 | 信号模型单元验证：频率、每转脉冲数、宽度、中心偏移、SSI 字跟踪、PFB、积分、X1+ 实机参数边沿一致性（参考 `casim` 的 19 项 pytest，MCU 侧以黄金模型位级比对复测） |
| VR-06 | 每项验收输出测试报告（沿用现有 Test_Report 格式）                                                                                                                 |

## 8 软件架构与非功能需求

| ID     | 需求                                                                                                                                                 |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| NFR-01 | 实时任务（信号生成 + SSI，定周期 10 µs / SSI 时钟节拍）与非实时任务（通信、记录、参数）严格分离；参数修改经双缓冲在转周期边界原子生效，保证信号连续 |
| NFR-02 | 信号模型与参数模型数据驱动（可配置文件化）；与 Python 参考实现 `casim` 的模型公式保持一致，便于交叉验证与移植（黄金模型比对）                      |
| NFR-03 | 扩展性：预留 GPIO（额外传感器通道）与 SPI/RS-485（额外 SSI 通道）                                                                                    |
| NFR-04 | 文档：用户手册、接线表（含通道表）、参数/默认值表、故障模式表、MCU 引脚分配表                                                                        |
